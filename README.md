Welcome to the Donut Delivery repository! This is a modern mobile/web application designed for artisanal donut lovers, offering an interactive menu featuring gourmet flavors, detailed descriptions, and precise nutritional macro breakdowns (Protein, Carbs, Fat, and Calories).

<h2>Features</h2>
- Artisanal Donut Menu: Browse through a curated collection of handcrafted, seasonal, and classic donuts.
<br>
- Detailed Descriptions: Each donut comes with an engaging marketing description highlighting its flavor profile and unique ingredients.
<br>
- Nutritional Macros: Complete transparency with calorie counts and macro nutrient breakdowns (Protein, Carbs, Fat) for every single item.
<br>
- Special Editions: Discover themed collections such as our Halloween Series and upcoming Christmas Edition (featuring adorable miniature gingerbread cookie toppers).
<br>
- User Authentication: Secure user sign-up and sign-in powered by Firebase Authentication.
<br>
- Cloud Storage: Dynamic asset management and image storage handled via Firebase Storage.
<br>
- Custom UI Design: Built with a vibrant, playful user interface featuring custom character backgrounds and themes.

<h2>Current Status & Roadmap</h2>
- <b>Phase 1 (Completed):</b>Content creation, UI asset integration, menu cataloging, and macro data schema finalization.
<br>
- <b>Phase 2 (Completed):</b> Core app structure, Firebase Authentication setup, and Firebase Storage integration for dynamic asset delivery.
<br>
- <b>Phase 3 (In Progress / Upcoming):</b>Shopping cart management, order placement, and checkout flow.

<h2>Tech Stack & Backend</h2>
- Framework: Flutter (Dart)
<br>
- Backend & Services: Firebase (Authentication, Storage)
<br>
- Design & Assets: Custom UI/UX graphics, Figma-inspired styling
<br>
<br>

Additionally, the ecosystem includes a companion <i>donuts_admin_app</i> designed for administrators to seamlessly manage and upload new donuts and their detailed contents directly to Firebase.
